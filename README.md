# MY DAILY PLANNER
A Student Daily Planner Application
Welcome to the My Daily Planner App! This application helps students organize their schoolwork, manage assignments, track deadlines, and monitor their daily academic progress.
## 📱 ABOUT THE PROJECT
The My Daily Planner is a student-friendly application designed to make schoolwork management easier, more organized, and accessible. Students can add, view, edit, delete, and track their school tasks in one place.
## ✨ FEATURES
* Dashboard – View your academic progress.
* Add Schoolwork – Create new school tasks.
* Edit Schoolwork – Update task information.
* Delete Schoolwork – Remove tasks.
* Schoolwork List – View all saved school activities.
* Task Status – Mark tasks as completed.
* Priority Levels – Organize tasks by priority.
* Due Dates – Monitor assignment deadlines.
* Automatic Dashboard Statistics – Track total, pending, and completed tasks.
* Firebase Integration – Store and manage schoolwork data.
* Responsive Design – Access the application on different screen sizes.
## 🛠️ TECHNOLOGIES USED
* HTML5
* CSS3
* JavaScript
* Firebase Authentication
* Firebase Cloud Firestore
* Visual Studio Code
* Live Server
How to Run the App
* Download or clone this repository.
* Open the project folder in Visual Studio Code.
* Install the Live Server extension if you don't have it.
* Right-click index.html and select Open with Live Server.
* Make sure you have an internet connection to access Firebase services
