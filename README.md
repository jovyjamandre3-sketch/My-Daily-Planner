# 🎓 MY DAILY PLANNER

📌 About the Application

My Daily Planner is a student-friendly application designed to help students manage their academic responsibilities by organizing school activities, assignments, and deadlines in one convenient place.

It helps students stay organized, keep track of their schoolwork, and manage their daily academic tasks more efficiently.

✨ Features

- Front Page – Welcomes users and provides access to the application.
- Dashboard – Displays the main menu and planning options.
- Add School Work – Allows users to add assignments, activities, and other academic tasks.
- View School Work – Allows users to view their saved schoolwork.
- Task Organization – Helps students organize their academic responsibilities.
- Deadline Management – Helps students keep track of upcoming deadlines.

📱 Application Navigation

The application consists of four main pages:

1. Front Page
2. Dashboard
3. Add School Work
4. School Work

Navigation Flow:

Front Page → Dashboard → Add School Work → School Work → Front Page

🛠️ Technologies Used

- HTML
- CSS
- JavaScript (if implemented)
- Firebase (if configured and connected)

🚀 How to Install and Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the "index.html" file.
4. Open the file using a browser or the Live Server extension in VS Code.
5. Start using My Daily Planner.

🎯 Purpose of the Application

The purpose of My Daily Planner is to provide students with a simple and convenient way to organize their school activities, monitor assignments, and remember important deadlines.
